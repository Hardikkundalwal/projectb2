# telc Deutsch B2 Learning Platform


A self-paced, exam-centered German learning platform built around telc Deutsch B2.


## Product principle
The intelligence should be in curriculum design, not flashy graphics or an AI button on every screen.


## Core UX
Map → Lesson → Cards → Exercise → Checkpoint → Progress


## Learning design
- Backward-design from telc B2 tasks.
- Teach only prerequisites needed to perform target tasks reliably.
- Use deterministic checking whenever possible.
- Use AI only where deterministic logic is insufficient.
- After failure: diagnose weakness → tiny repair → retry → update mastery → schedule review.
- Let stronger learners skip mastered prerequisites via diagnostic onboarding.
