# Curriculum overview

The architecture contains exactly **132 nodes**.

| Module | Nodes | Purpose |
|---|---:|---|
| foundation | 18 | Cross-module prerequisite and diagnostic readiness |
| reading | 24 | Leseverstehen Teile 1–3 |
| language_elements | 24 | Sprachbausteine Teile 1–2 |
| listening | 18 | Hörverstehen Teile 1–3 |
| writing | 18 | Schriftlicher Ausdruck: halbformelle E-Mail |
| speaking | 18 | Mündlicher Ausdruck Teile 1–3 |
| integration | 12 | Module checkpoints, mock exams, repair and readiness |

## Design

Every node has a learner outcome, exam alignment, prerequisites, practice modes, mastery evidence, remediation, status, and copyright rule. Foundation nodes supply reusable language/strategy prerequisites. Each exam module ends in an aligned checkpoint. Integration nodes generate the path, run simulations, diagnose weaknesses, and make a conservative readiness decision.

Machine-readable truth: `NODE_DEFINITIONS.json`. Portable inventory: `NODE_CATALOG.csv`. Dependencies: `SKILL_GRAPH.json`.
