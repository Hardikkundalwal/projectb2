# Architecture decisions

- ADR-001: content files are canonical and imported atomically.
- ADR-002: attempts are append-only; mastery is derived.
- ADR-003: deterministic scoring precedes AI.
- ADR-004: written and oral readiness are separate gates.
- ADR-005: 132 nodes are stable curriculum units; lessons may version independently.
- ADR-006: official sources inform facts only; production content is original.
